# Fictional Multilingual CSV Examples

These six small CSV files are synthetic public examples created for this
portfolio project. They imitate English, Indonesian, and German/SAP-style field
names without containing the original private source records.

- Customer A: English abbreviations
- Customer B: Indonesian field names
- Customer C: German/SAP-style field names

Each customer has one customer table and one order table. The four rows per
file intentionally include mixed date formats, missing phone markers, and
different status vocabularies.
